## Logo prompt

> Use case: logo-brand. Create a single refined app icon for KOL, a minimal Windows clipboard history app. The name plays on French colle (glue) and copier-coller. Design one distinctive compact symbol combining two overlapping rounded paper/sticker shapes, the front sheet with a subtly peeled corner, suggesting copies sticking together. Dark ink green body and soft fresh mint accent, warm professional friendly editorial utility aesthetic. Flat vector-like geometry, optically balanced thick silhouette, excellent recognition at 16px. Centered square composition, generous transparent padding. Icon symbol only, no text, no letters, no mockup, no shadows outside symbol, no gradient, no border. Transparent background. This is a finished production app icon.

## Panel concept

The initial generated reference is `panel-concept.png`. Its prompt requested a complete compact French Windows clipboard panel, white surface, mint selection, Segoe UI typography, KOL header, search, five filters, six mixed clipboard rows and a quiet local-capture footer. It was an initial visual reference, not a screenshot of the finished app.

The user's subsequent review explicitly supersedes the initial row design: compact text-only copy rows, permanent trash and pin controls with a stable timestamp, large image previews under their label, optional information via right-click, no size/copy-count/type sublines, no routine partial-format warning in the daily list, and Ctrl+F for search. The logo, palette and general panel structure remain the same.
